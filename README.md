# 🏝️ 数感探索乐园

和跳跳一起认识数字，培养数感！

## 🎮 游戏模块

1. **👀 数一数** - 感知数量，学会估算
2. **📦 凑十魔法** - 理解十进制
3. **🏠 数字搬家** - 理解位值
4. **🌉 过河冒险** - 进退位感知
5. **🛒 购物乐园** - 人民币换算

## 🚀 本地运行

```bash
# 方法1：用 Python 启动
cd math-land
python3 -m http.server 8080

# 方法2：用 Node.js
npx serve .

# 然后打开浏览器访问
# http://localhost:8080
```

## 📱 在手机上测试

确保手机和电脑在同一网络，然后访问：

```
http://<你的电脑IP>:8080
```

## 🎯 设计理念

- **图形交互为主** - 文字极少，用图形和动画引导
- **探索式学习** - 不是做题，是理解数字
- **即时反馈** - 每次操作都有视觉和音效反馈
- **零压力** - 答错不扣分，鼓励继续探索

## 🛠️ 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- Web Audio API 音效合成
- 触摸事件支持移动端
- 本地存储保存进度
