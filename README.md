## 🏠 生活板块：数字钱包（财商启蒙）

主页「生活板块 → 数字钱包」：让孩子在真实场景里理解"钱"。

- **挣钱**：完成家长配置的家务任务（扫地 +1 元、叠衣服 +2 元…），每个任务每天一次
- **花钱**：点消费项（玩手机、吃零食、买玩具…）确认扣钱，余额不足会提示先去挣钱
- **储蓄罐（复利）**：把零钱存入储蓄罐，**每天按利率（默认 1%）复利结息**——
  存得越久长得越多，配"复利小课堂"文案，直观理解"钱生钱"
- **家长设置**：🔒 入口 + 4 位 PIN（默认 `0000`），可增删任务/消费项、调利率、改 PIN、重置钱包
- 金额用「分」整数运算（无浮点误差），存/取钱用步进器（+1/-1/+5/-5），顺带练加减法
- 纯本地存档（`core/wallet.js`），所有收支有历史记录

## ⭐ 闯关机制（设计定稿）

- **星级制 + 不失败**：答错温和提示（"再数数看～"），原地重试直到答对，不扣命、不重来
- **星级 = 首答正确率**：全对 3⭐ / ≥80% 2⭐ / 通关 1⭐，攒星解锁下一关
- **数字精灵庆祝**：答对数字 N（1~10），精灵 N 跳出来欢呼（纯即时反馈，不影响玩法）
- **听音数数**：进入题目自动播放，可点喇叭"再听一次"，重听不扣首答
- **纯本地存档**：进度保存在手机本地（`core/storage.js` 已封装，将来可平滑升级云同步）
- **吉祥物跳跳** 🐸：多表情状态机 + 随机鼓励语，贯穿全程情感反馈

## 🛠️ 技术栈

- 原生微信小程序（无框架、无构建链）

孩子可以问数学问题（预设问题一键提问或自己输入），
AI 以"跳跳"小青蛙老师的口吻用低龄语言回答。走**云函数转发**，调用
`https://chatapi.weixin.qq.com/openai/v1/chat/completions`（OpenAI 兼容格式，模型 `GLM-5.2`）。

- **儿童安全**：系统提示词在云函数侧注入（前端无法绕过），约束回答温柔、简短（≤80 字）、只讲数学、不含不良内容
- **鉴权可配置**：云函数环境变量 `AI_API_KEY`，为空则不带 Authorization 头；可填裸 key 或 `Bearer xxx`
- **防滥用**：单条消息限 500 字、最多保留 10 轮对话；接口超时 20s、错误信息友好化

### 部署步骤

1. **开通云开发**：微信开发者工具 → 工具栏「云开发」→ 开通并创建环境
2. **上传云函数**：在 `cloudfunctions/aiChat` 目录右键 → 「上传并部署：云端安装依赖」
3. **配置环境变量**（云开发控制台 → 云函数 → aiChat → 配置）：
   | 变量 | 说明 | 默认 |
   |---|---|---|
   | `AI_API_URL` | 接口地址 | `https://chatapi.weixin.qq.com/openai/v1/chat/completions` |
   | `AI_MODEL` | 模型名 | `GLM-5.2` |
   | `AI_API_KEY` | 鉴权凭证（可选） | 空 |
4. 编译预览 → 主页点「问跳跳」即可对话

> ⚠️ 未开通云开发时，AI 页会显示提示，游戏本体不受影响（AI 板块是可选功能）。
