# 🏝️ 数感探索乐园（math-land）

微信小程序 · 小学数学 · 游戏闯关。和跳跳一起认识数字，培养数感！

## 🎮 当前进度

**模块一「数一数」**（8 关，对应一年级数感启蒙）：点数/十格阵/感数/一一对应/比较/按群计数

**模块二「凑十魔法」**（6 关，对应十进制/凑十法）：

| 关 | 主题 | 玩法 |
|---|---|---|
| 1 | 补满十格阵 | 点格子补到 10（补数）|
| 2 | 十的拆分 | 10 = □ + □，选两个数 |
| 3 | 凑十伙伴 | 4 个数里找两对和 = 10 配对 |
| 4 | 补数练习 | a + □ = 10，十格阵可视化 |
| 5 | 凑十加法 | a + b 先凑 10 再算（b ≥ 10-a）|
| 6 | 魔法挑战 | 混合练习 |

> 模块三~五（数字搬家/过河冒险/购物乐园）为占位卡片，开发中。

| 关 | 主题 | 题型 | 核心能力 |
|---|---|---|---|
| 1 | 认识 1~3 | 点数选数 | 小量点数 |
| 2 | 认识 4~5 | 点数选数 | 点数与认数 |
| 3 | 认识 6~8 | 点数 + 十格阵 | 有序计数 |
| 4 | 认识 9~10 | 点数 + 十格阵 | 大点数 |
| 5 | 谁多谁少 | 比较多少 | 数量比较 |
| 6 | 跳跳的晚餐 | 一一对应 | 一一对应 |
| 7 | 火眼金睛 | 一眼报数 | 感数（估算） |
| 8 | 两人一组 | 按群计数 + 找数量 | 按群计数 |

## ⭐ 闯关机制（设计定稿）

- **星级制 + 不失败**：答错温和提示（"再数数看～"），原地重试直到答对，不扣命、不重来
- **星级 = 首答正确率**：全对 3⭐ / ≥80% 2⭐ / 通关 1⭐，攒星解锁下一关
- **纯本地存档**：进度保存在手机本地（`core/storage.js` 已封装，将来可平滑升级云同步）
- **吉祥物跳跳** 🐸：多表情状态机 + 随机鼓励语，贯穿全程情感反馈

## 🛠️ 技术栈

- 原生微信小程序（无框架、无构建链）
- WXML + WXSS（emoji 极简视觉，零图片素材）+ CSS 动画
- `InnerAudioContext` 合成音效（`assets/sounds/`，可用 `tools/gen_sounds.py` 重新生成）
- 全部交互为点选/点击（儿童触屏友好，无拖拽）

## 🚀 本地开发

1. 打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择本仓库根目录
3. `project.config.json` 中的 `appid` 目前是测试号（`touristappid`），
   正式开发请替换为你自己的小程序 AppID（或使用「测试号」预览）
4. 编译预览即可游玩

> ⚠️ 本仓库尚未配置 `.gitignore` 忽略微信开发者工具自动生成的
> `project.private.config.json`，如出现请自行加入。
